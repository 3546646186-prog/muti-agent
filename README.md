# 理性讨论圆桌 v2

这是 muti-agent PR #2 的新版前端和你的「人格数据库」合并后的程序，只保留理性讨论。


## 文件夹

- backend：人格数据库的副本，外加网页服务 服务.py（人物、性格库、讨论引擎都在这里）
- frontend：PR #2 前端的副本，已经改成连接 backend；dist 是构建好的网页
- persona-protocol：前端图鉴用到的人物格式规则

## 怎么用

1. 打开 PowerShell，进入 backend 文件夹：

       cd backend
       python 服务.py

2. 浏览器打开 http://127.0.0.1:8000
3. 输入议题（或点一个示例），设好轮数（2 到 6）和每次发言字数上限
4. 选 2 到 5 个人物，每人选 1 到 3 个性格、1 个说话风格，点「进入圆桌」
5. 大家入座后，在右下角先说一句你的理解或背景（只说“开始吧”也行），发送后讨论开始
6. 讨论中可以随时插话；点某个成员可以只对他说话，也能只看他的发言
7. 结束后右侧显示主持人总结，完整记录保存在 backend/讨论记录

首页的「图鉴」可以查看每个人物的详细资料。

## 其他

- 不想花 API 额度时，可以用 python 服务.py --试跑 启动，发言会用示例文字代替
- 8000 端口被占用时，用 python 服务.py --端口 9000 换一个端口
- 改了前端代码后，在 frontend 里运行 pnpm build 重新构建
- 第一次用：把 backend/模型配置.示例.json 复制一份改名为 模型配置.json，填上自己的 API Key（这个文件不会上传到 GitHub）
